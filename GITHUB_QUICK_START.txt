TROUBLESHOOTING:

Q: Authentication fails when pushing
A: Use: git remote set-url origin git@github.com:YOUR_USERNAME/repo.git

Q: Files not appearing after push
A: Run: git push -u origin main --force (only for fresh repos)

Q: Documentation links broken
A: GitHub is case-sensitive for filenames. Check CONTRIBUTING.md not contributing.md

Q: Repository too large
A: .gitignore properly excludes build artifacts. Should be <50MB
